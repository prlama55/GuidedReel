# GuidedReel user guide

GuidedReel turns a script and a handful of images, clips and audio files into a finished video. You pick a format and a template, write or paste your script, drop in media, tune the timing, and export an MP4. It runs in the browser and as a desktop app for macOS, Windows and Linux, and both share the same editor and video engine.

## Concepts in one minute

- A **project** is one video. It has a format (9:16, 16:9, 1:1 or 4:5), a frame rate, a brand kit, scenes and assets.
- A **scene** is one beat of the story: a hook, a title, a feature, a quote, a product, an image, a clip, a call to action. Each scene has text, optional media, a duration and a transition into it.
- A **template** is a ready-made sequence of scenes with sample text. You start from one, then change anything.
- **Assets** are the files you bring: images, videos, audio, voiceovers, music, logos and fonts.
- **Overlays** are text, media or emoji stickers placed freely on top of a scene.
- **Export** renders the project to a video file. On the web the server renders and you download the result. On desktop the render happens on your computer.

Nothing in the first version uses AI. Every word and every picture is yours. Optional voice generation and background music are produced from your text and your scene structure, and they only run when you ask for them.
